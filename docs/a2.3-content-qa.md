## Discovery metadata

The shared template emits a deployment-owned canonical origin only for GET
routes that are safe to index. It never derives a canonical URL from the Host
header or query string. Admin, account, cart, order, health, survey, waitlist,
robots, and other session-bearing routes omit canonical/Open Graph/X metadata
and emit `noindex, nofollow, noarchive`. The private POC also emits that
directive for all rendered pages. `robots.txt` is no-store and disallows all
robots in local/private POC environments; a non-private public profile allows
safe public pages while disallowing sensitive paths.
